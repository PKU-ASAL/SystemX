# SysArmor v1 MVP Changelog

Date: 2026-06-14

## Summary

v1 delivers the first end-to-end SysArmor MVP. It turns the original design-first repository into a runnable Go prototype with real agent, manager, CLI, proto contracts, container/VM e2e harness, and scenario assertions.

Primary path:

```text
Tetragon JSONL / replay SensorEvent JSONL
  -> sysarmor-agent
  -> normalize + endpoint fastpath
  -> AgentDataPlaneService.AppendBatch
  -> sysarmor-manager
  -> MVP analytics + store
  -> sysarmorctl JSON query
  -> test harness assert/report
```

## Added

### Project Foundation

- Added Go module and top-level `Makefile`.
- Added generated protobuf contracts under `api/proto`.
- Added build targets:
  - `make api`
  - `make build`
  - `make test`

### Binaries

- Added `cmd/sysarmor-agent`.
  - Reads replay `SensorEvent` JSONL.
  - Reads live Tetragon JSONL via `--stream-jsonl`.
  - Normalizes events and emits endpoint signals.
  - Uploads batches over HTTP or gRPC AgentDataPlaneService.
- Added `cmd/sysarmor-manager`.
  - Provides ingest, query, recompute, metrics, and health endpoints.
  - Hosts generated AgentDataPlaneService gRPC service.
- Added `cmd/sysarmorctl`.
  - Queries agents, events, signals, incidents, metrics, status, and recompute results.
  - Provides stable JSON output for tests.

### Agent And Endpoint

- Added Tetragon JSONL adapter.
- Added process normalization with:
  - `stable_id`
  - `lineage_id`
  - `seq`
  - `raw_ref`
- Added endpoint context and raw ring buffer.
- Added stream batching with configurable batch size and flush interval.
- Added endpoint fastpath MVP rules:
  - `web_runtime_spawns_shell`
  - `download_by_lolbin`
  - `payload_dropped`
  - `reverse_shell_pattern`
  - `sensitive_cred_read`
  - `suspicious_exec_connect`

### Manager And Analytics

- Added file-backed MVP store for agents, events, signals, incidents, and metrics.
- Added idempotent upsert for repeated events, signals, and incidents.
- Added scenario-level recompute for streaming uploads.
- Added cloud signals:
  - `dropped_payload_executed_and_connects`
  - `web_shell_chain`
- Added MVP incident convergence with:
  - `ConvergeTrace.method = rarity+causal-topk`
  - cross-lineage stitching
  - additive threshold control mode
- Added recompute controls:
  - `cloud.cross_lineage`
  - `additive_threshold`

### Test Harness

- Wired container topology to run real manager and agent binaries.
- Wired VM topology to run manager/ctl in `mgr` VM and agent stream in `node-a` VM.
- Added replay generator for deterministic scenario inputs.
- Added stream smoke capture for Tetragon -> agent -> manager path.
- Added container-side Tetragon filtering by `node-a` Docker id to avoid host/container noise.
- Added contract assertions through `sysarmorctl`.
- Added report matrix for replay, stream, and perf results.
- Added perf smoke script for `tetra getevents`.

### Documentation

- Added root `README.md`.
- Added `configs/README.md`.
- Updated `test/README.md`.
- Added implementation handoff plan.
- Updated MVP design document to summarize current state and remaining project gaps.

  - Endpoint terminal is emitted.
  - Cloud chain is emitted.
  - Exactly one incident is created.

  - Normal mode creates zero incidents.
  - Additive-threshold control mode can create an incident.

## Known Limits

- Agent is still a command-style streamer/uploader, not a daemon.
- Sensor runtime is not yet formally managed by agent.
- Endpoint and cloud rules are compiled Go heuristics, not content-pack rules.
- Store is file-backed JSON, not SQLite/Postgres.
- AgentDataPlaneService.AppendBatch is unary data append; AgentControlPlaneService.Connect carries control flow.
- Policy/control plane is limited to recompute controls.
- Analytics is MVP convergence, not a full graph/rarity/correlate pipeline.
- CLI is primarily a JSON query boundary for tests.
- Deployment artifacts such as systemd units and Helm charts are not included.
